# MindSpace Youth

MindSpace Youth is a Vue 3 web application for a youth mental health charity.

## Business Requirements A-C

- BR A.1: Built with Vue 3 and Vite.
- BR A.2: Responsive layout for mobile, tablet and desktop.
- BR B.1: Form validation for required fields, email format, password length, password match, dates and rating range.
- BR B.2: Dynamic data rendered from Vue state and persisted with localStorage.
- BR C.1: Basic register, login and logout authentication.
- BR C.2: Role-based access for `young_user` and `admin`.
- BR C.3: Aggregated rating score with average rating and total reviews.
- BR C.4: Basic security practices including client-side validation, input length limits, escaping through Vue text binding, and avoiding `v-html`.

## Run

```bash
npm install
npm run dev
```
