# 🧠 MindSpace Youth

> A mental health and wellbeing platform for young people — built with Vue 3 and Firebase.

MindSpace Youth is a single-page application (SPA) designed to support young people with mental health resources, wellbeing check-ins, and community feedback. It features role-based authentication, dynamic data persistence with Firestore, and a responsive, accessible interface.
